# Project instructions

- Use four spaces for indentation, no tabs, in all source and configuration files.
- After every change, run `pwsh -File scripts/lint.ps1`. Before completion all checks must pass; report any environment blockers explicitly.
- To format, run `pwsh -File scripts/lint.ps1 -Fix`, then run the checks again.
- Go formatting uses gofmt followed by replacing each tab with four spaces, as requested by the owner.
- Keep money as integer minor units and preserve transactional, idempotent bet placement.
